# About the story editor

This is the visual authoring environment of
[LODEON](https://gitlab.rlp.net/adwmainz/digicademy/lodeon/lodeon-core), built
into SHMARQL to write data stories about the knowledge graphs this site gives
access to.

A data story combines narrative text with live SPARQL queries, Plotly and
RAWGraphs visualizations, maps, local media, IIIF objects, remote embeds,
Graph Explorer views, music notation and structured publication metadata.

Projects are stored locally in your browser and can be exported as portable
`.lodeon.zip` packages, which can also be opened in a full LODEON instance.
The SHMARQL server is used to run read-only SPARQL queries, to preview
stories, and to publish them as pages of this site.

This editor is LODEON without its AI Assistant: it makes no calls to language
models or other external tools.

LODEON was conceived and implemented within
[NFDI4Culture](https://nfdi4culture.de), the consortium for research data on
material and immaterial cultural heritage within the German National Research
Data Infrastructure.
